# media-src — исходники фото и видео Кати

Сюда кладутся оригиналы. Сайт их не трогает: команда `npm run media` сама нарезает
размеры (AVIF, WebP, JPEG), пережимает ролики в MP4 H.264 с постером и обновляет
`src/content/media.generated.json`. Руками этот JSON не правится — его перезапишет следующий запуск.

## Куда что класть

Все работы живут в одном разделе — «Портфолио». С 01.11.2026 (правка Кати: «нужно разделять не только
что это за проект, но и отдельно монтаж / сторис / статистика») папка = **тип работы**, а проект — плашка
на самой работе в просмотре. В SMM, Контент-съёмке, Видеомонтаже и Брендинге примеров работ нет.

| Папка | Раздел сайта | Что класть |
|---|---|---|
| `hero/hero.png` | 01 Главный экран | портрет (уже лежит) |
| `about/about.png` | 02 Обо мне | второй портрет (уже лежит; на телефоне скрыт — просьба Кати) |
| `portfolio/<тип>/<слайд>/` | 08 Портфолио | папка-коллаж (`reels`, `stories`, `ads`): одна подпапка = один слайд-кейс |
| `portfolio/<тип>/<проект>/` | 08 Портфолио | папка поштучно (`smm-results`, `identity`, `print`): работа = слайд |
| `portfolio/<тип>/` (без подпапки) | 08 Портфолио | работы без названного заказчика — идут последними, без плашки |

Типы сейчас: `reels`, `stories`, `ads`, `smm-results`, `identity`, `print`, `ai-video`. Порядок внутри
подпапки — по имени файла, поэтому файлы называются `01-…`, `02-…`.

**Папка-коллаж** (правка Кати 01.11 днём: «чтобы на одном слайде было размещено по 2–4 фото/видео»,
«чтобы сразу один сторителлинг был на одном слайде»). Слайды перечислены в `slides` у папки в
`src/content/projects.ts`, в порядке её альбома: `{ dir: 'wow-brows', project: 'wow' }`. Подпапка слайда
называется как угодно (`anna-soul-1`, `wow-pedicure`), проект задаёт поле `project`, подпись под коллажем —
его название и ниша. Слайд из двух кейсов («оптика и кинолог соедини в одном слайде») —
`projects: ['dog-trainer', 'optics']`: проект каждого файла по порядку, подпись встаёт под каждой работой.
Строка под подписью — `note` на трёх языках (у WOW в монтаже: «Съёмка и монтаж — мои»).
Раскладку рядов считает `src/components/collage.ts` от размера экрана; на слайде лучше 2–6 работ:
больше шести на телефоне становятся мелкими (тест `interaction.spec.ts` ловит работу ниже 120 px).

**Папка поштучно:** подпапки идут в порядке `projects` у папки, каждая работа — отдельный слайд.

Обложка превью — первая работа папки (для ролика — его постер) или файл из поля `cover`, путь внутри папки
без расширения: `cover: 'wow/04-interior-signage'`, `cover: 'wow-brows/01-brows-why'`.

Превью квадратное и берёт середину кадра, поэтому может зацепить подпись или логотип с доски. Два поля:
- `coverZoom` — во сколько раз приблизить и к какой точке прижать: `{ scale: 1.35, origin: '50% 0%' }` — ×1,35 от верха;
- `coverPosition` — какую часть кадра взять в квадрат (CSS object-position): `'0% 50%'` — левый край горизонтального слайда.

В полноэкранном просмотре файл всё равно виден целиком. После новой обложки посмотреть превью на телефоне
и компьютере, замерить край надписи и добавить его в `COVERS` в `tests/e2e/composition.spec.ts`.

**Новый проект:** название и ниша — в `PROJECTS` в `src/content/projects.ts` (на трёх языках; ниша необязательна).
В папке-коллаже — новый слайд в `slides` и файлы в `portfolio/<тип>/<dir>/`; в папке поштучно — ключ в
`projects` и файлы в `portfolio/<тип>/<ключ>/`. Названия заказчиков — только те, что назвала Катя:
придуманные «Бьюти» и «Утро невесты» она отклонила.

**Новый тип работы:** папка `portfolio/<латиница-через-дефис>/` и запись в `PORTFOLIO_ITEMS`. Папку или подпапку
без записи сайт не покажет, и тест `content.test.ts` упадёт: так лишняя папка не потеряется молча.

**Новый файл в существующую папку:** просто положить и запустить `npm run media`.

Форматы: фото `.jpg .jpeg .png .webp .avif .tif`, видео `.mp4 .mov .m4v .webm`.
HEIC с iPhone скрипт не читает — сначала перевести в JPEG
(`ffmpeg -i IMG.heic -frames:v 1 -q:v 2 IMG.jpg`).
Фото лучше от 1600 px по длинной стороне, видео — исходник без пережатия: сжатие сделает скрипт.

## Подписи: meta.json рядом с файлами

Необязательный файл в той же папке. Ключ — имя файла без расширения:

```json
{
  "01-reel-salon": {
    "alt": { "ru": "Reels для бьюти-салона", "uk": "Reels для б'юті-салону", "en": "Reels for a beauty salon" }
  }
}
```

`alt` — что видно на кадре (читают экранные дикторы и поисковики). Без него подставится
подпись вида «Stories — WOW Beauty Lab · Салон красоты на Кипре, 3». Названия папок и проектов задаются
не здесь, а в `src/content/projects.ts`.

У ролика можно задать `posterAt` — секунду кадра для обложки. По умолчанию берётся 0,5 с,
и у роликов с затемнением в начале обложка выходит чёрной (так было у AI Video, теперь там `6`):

```json
{ "01-ai-video": { "posterAt": 6 } }
```

## После добавления файлов

```
npm run media     # нарезать и обновить список
npm run check     # типы, тесты, сборка, проверка цен, браузерные тесты
```

Готовые файлы ложатся в `public/media`, полноразмерные кадры для обложек роликов — в `.media-cache`
(в сайт не попадают). Класть в `public/media` что-то руками нельзя: юнит-тест падает на любой файл,
на который сайт не ссылается.

Если меняется портрет на главном экране — поправить `data-face-box` в `src/sections/Hero.tsx`
(где на фото лицо, доли ширины и высоты): по нему тест проверяет, что текст не наезжает на лицо.

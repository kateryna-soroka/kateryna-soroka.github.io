# Катерина Сорока — сайт-портфолио

SMM, контент-съёмка, видеомонтаж, брендинг. Три языка: украинский `/`, русский `/ru/`, английский `/en/`.

Сайт статический: при сборке каждая языковая версия превращается в готовый HTML (текст виден поисковикам
без JavaScript), фото и видео уже пережаты и лежат в `public/media`.

## Как сайт попадает в интернет

GitHub собирает и выкладывает его сам — `.github/workflows/deploy.yml`:

1. push в ветку `main` (или вручную: **Actions → Deploy → Run workflow**);
2. GitHub ставит зависимости, гоняет тесты, собирает `dist/` и проверяет, что на сайте нет цен;
3. готовый `dist/` уходит на GitHub Pages.

Адрес сайта сборка берёт из настроек Pages. От него зависят canonical, hreflang, og:image и `sitemap.xml`,
поэтому **после смены адреса (подключили свой домен) сборку надо запустить ещё раз** — вручную, кнопкой выше.

Сайт открывается только из корня адреса. Подходит репозиторий `<ник>.github.io` или свой домен.
Адрес вида `<ник>.github.io/<репозиторий>/` сборка остановит с понятной ошибкой: на нём сайт развалился бы.

## Свой домен

1. Settings → Pages → **Custom domain** → вписать домен (например `example.com`) → Save.
2. У регистратора домена в DNS:
   - четыре записи `A` для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - четыре записи `AAAA` для `@`: `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`;
   - `CNAME` для `www` → `<ник>.github.io`.
   Записи вида `*` (wildcard) не ставить.
3. Когда проверка DNS пройдёт (до суток) — включить **Enforce HTTPS**.
4. Actions → Deploy → **Run workflow**: пересобрать сайт под новый адрес.

Файл `CNAME` в репозитории не нужен — при выкладке через Actions GitHub его не читает.

## Команды

Нужен Node.js 22.12 или новее.

```bash
npm ci                 # зависимости
npm run dev            # локально с горячей перезагрузкой
npm run build          # сборка в dist/ (адрес: SITE_URL=https://домен npm run build)
npm run preview        # посмотреть собранное: http://localhost:4173
npm test               # проверки содержимого
npm run check:prices   # на сайте не должно быть цен
npm run test:e2e       # проверки в браузере (один раз перед этим: npx playwright install chromium)
```

Без `SITE_URL` сборка считается предпросмотром: страницы закрыты от индекса (`noindex`), без canonical и sitemap.

## Фото и видео

Готовые файлы — в `public/media`, их список — в `src/content/media.generated.json`. Руками не править.
Оригиналы в репозиторий не входят (весят почти гигабайт), из них здесь только портрет `media-src/hero/hero.png` —
по нему сборка делает картинку для превью ссылки. Поэтому `npm run media` здесь не запускается и сам остановится:
новые работы добавляются там, где лежат оригиналы, и приходят сюда уже готовыми.

Тексты на трёх языках — `src/content/i18n/`, работы портфолио — `src/content/projects.ts`.
